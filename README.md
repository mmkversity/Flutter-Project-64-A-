# Project 64A (Flutter Task Manager)

A modern, responsive task management application built with Flutter and Material 3 design.

## Features

- **Custom App Bar**:
  - Clean Material 3 styling and title.
  - Interactive action buttons (Reload, Notifications, Profile, and Options Menu).
- **Notification Feature**:
  - Interactive notification icon button with dynamic unread badge count in the App Bar.
  - Interactive bottom sheet displaying task alerts, reminders, and achievements.
  - Mark individual notifications as read or mark all as read.
  - Dismissible notifications with swipe-to-delete and "Clear all" support.
- **Profile Feature**:
  - Profile avatar button in the App Bar.
  - Interactive profile sheet displaying user details and avatar.
  - Live task performance statistics (Total, Active, Done, and Completion Rate %).
  - Account and appearance options, about dialog, and sign-out action.
- **Task Management**:
  - Add tasks with title and optional notes.
  - Filter by All, Active, and Done.
  - Mark tasks complete/incomplete.
  - Delete with SnackBar Undo.
  - Clear completed tasks.

## Getting Started

### Prerequisites
- [Flutter SDK](https://flutter.dev/docs/get-started/install) (3.x or newer)

### Run the App
```bash
flutter pub get
flutter run
```

### Run Tests
```bash
flutter test
```

### Code Analysis
```bash
flutter analyze
```
